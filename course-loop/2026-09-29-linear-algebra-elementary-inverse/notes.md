## 1. 分块矩阵补全

分块乘法仍按普通矩阵乘法的形式进行，但每个子块乘积必须先满足维数条件。

课件例中：

`A = [[E, O], [A1, E]]`，`B = [[B11, E], [B21, B22]]`

逐块相乘得到

`AB = [[B11, E], [A1B11+B21, A1+B22]]`。

关键是利用单位块 `E` 和零块 `O` 简化计算，而不是重新把整个矩阵展开。

## 2. 按行、按列分块

若 `A = (A1, A2, ..., An)`，则

`Ax = x1A1 + x2A2 + ... + xnAn`。

所以 `Ax` 是 `A` 的列向量的线性组合。

若 `A` 按行分块为 `alpha1, ..., alpha_m`，则

`xA = x1 alpha1 + ... + xm alpha_m`。

若 `B = (B1, ..., Bs)`，则

`AB = (AB1, ..., ABs)`。

若 `A` 按行分块，则 `AB` 的每一块行分别是 `alpha_i B`。

## 3. 分块转置

对分块矩阵转置时，不仅要交换子块的位置，还要转置每个子块：

`(A_ij)^T = A_ji^T`。

## 4. 矩阵的初等变换

三类初等行变换：

1. 对换变换：`ri <-> rj`。
2. 倍乘变换：`ri * k`，其中 `k != 0`。
3. 倍加变换：`ri + k rj`。

初等列变换的定义类似，把 `r` 换成 `c`。初等行变换和初等列变换统称为初等变换。

初等变换都是可逆的，因此线性方程组经过初等变换后仍然同解。

## 5. 行阶梯形

相关概念：

- 零行：元素全为零的行。
- 非零行：元素不全为零的行。
- 非零首元：非零行从左数第一个非零元素。

行阶梯形矩阵：

1. 若有零行，零行在最下方。
2. 非零首元的列指标随行指标严格递增。

任何矩阵都可以经过初等行变换化为行阶梯形。

## 6. 行最简形

行最简形矩阵在行阶梯形的基础上，还要满足：

1. 非零首元都是 `1`。
2. 非零首元所在列的其余元素都是 `0`。

任何矩阵都可以经过初等行变换化为行最简形。

## 7. 矩阵等价与等价标准形

若矩阵 `A` 可经有限次初等变换化为 `B`，则称 `A` 与 `B` 等价或相抵。

等价关系满足：

1. 反身性：`A` 与 `A` 等价。
2. 对称性：若 `A` 与 `B` 等价，则 `B` 与 `A` 等价。
3. 传递性：若 `A` 与 `B` 等价，`B` 与 `C` 等价，则 `A` 与 `C` 等价。

任一 `m x n` 矩阵都可经初等变换化为等价标准形：

`[[E_r, O], [O, O]]`。

每个矩阵的等价标准形唯一。

标准分解：

存在 `m` 阶可逆矩阵 `P` 和 `n` 阶可逆矩阵 `Q`，使得

`A = P E_mn^(r) Q`。

## 8. 初等矩阵

由单位矩阵经过一次初等变换得到的矩阵称为初等矩阵。

三类初等矩阵：

1. `E(i,j)`：交换第 `i`、`j` 行或列。
2. `E(i(k))`：第 `i` 行或列乘 `k`。
3. `E(i,j(k))`：第 `i` 行加第 `j` 行的 `k` 倍，或第 `i` 列加第 `j` 列的 `k` 倍。

核心规则：

- 对 `A` 做一次初等行变换，相当于在 `A` 的左边乘相应初等矩阵。
- 对 `A` 做一次初等列变换，相当于在 `A` 的右边乘相应初等矩阵。
- 口诀：行左列右。

## 9. 初等矩阵的逆

`E(i,j)^-1 = E(i,j)`

`E(i(k))^-1 = E(i(1/k))`

`E(i,j(k))^-1 = E(i,j(-k))`

因此，初等矩阵都可逆，而且初等矩阵的逆矩阵仍是初等矩阵。

## 10. 逆矩阵的定义与性质

设 `A` 是方阵。若存在同阶方阵 `B`，使

`AB = BA = E`，

则称 `A` 可逆，`B` 是 `A` 的逆矩阵，记作 `B = A^-1`。

逆矩阵唯一：

若 `B`、`C` 都是 `A` 的逆矩阵，则

`B = BE = B(AC) = (BA)C = EC = C`。

基本性质：

`(A^-1)^-1 = A`

`(A^T)^-1 = (A^-1)^T`

`(kA)^-1 = k^-1 A^-1`，其中 `k != 0`

`(AB)^-1 = B^-1 A^-1`

多个矩阵乘积求逆必须完全反序：

`(A1...Am)^-1 = Am^-1 ... A1^-1`。

## 11. 可逆性的初等变换判定

`A` 可逆当且仅当 `A` 可以写成若干初等矩阵的乘积。

`A` 可逆当且仅当 `A` 可经初等行变换化为单位矩阵 `E`。

可逆的行最简形矩阵只能是 `E`。

## 12. 易错点

1. 分块乘法只检查外部形状，不检查子块乘法的内部维数。
2. 分块转置时只交换子块位置，忘记对子块转置。
3. 误把初等行变换写成右乘初等矩阵。
4. 混淆行阶梯形与行最简形的条件。
5. 乘积求逆忘记反序，误写 `(AB)^-1 = A^-1 B^-1`。
6. 把矩阵等价与矩阵相等混为一谈。
