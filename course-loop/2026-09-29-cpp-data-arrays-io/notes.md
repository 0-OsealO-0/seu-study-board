## 1. 基本数据类型

课件把 C++ 基本数据类型分为：

1. 整型：`short int`、`int`、`long int`。
2. 字符型：`char`。
3. 布尔型：`bool`。
4. 浮点型：`float`、`double`、`long double`。

不同数据类型决定数据的表示方式、取值范围和可执行的运算。

## 2. 变量

变量是程序运行期间其值可以改变的量。

变量命名规则：

- 由字母、数字和下划线组成。
- 首字符必须是字母或下划线。
- 不能使用关键字。
- 不能包含点、井号、问号、空格等字符。

合法示例：`sum`、`Student_name`、`tan4`、`BASIC`、`li_ling`。

不合法示例：`M.D.John`、`$123`、`#33`、`3G64`、`Ling li`。

变量必须先定义后使用：

```cpp
float a, b, c, d, e;
int x, y;
```

定义变量时可以初始化：

```cpp
float a=83.5, b, c=64.5, d=81.2, e;
```

未初始化的变量值不可预测，不能假定为 `0`。

## 3. 文字常量

文字常量是程序中直接给出的量，可分为数值型常量和字符型常量，也可分为直接常量和符号常量。

### 整型常量

三种写法：

```cpp
1357     // 十进制
012      // 八进制，值等于十进制 10
0X32A    // 十六进制，值等于十进制 810
```

`12L` 可表示 `long int` 型常量。

### 浮点型常量

可以用十进制小数或指数形式：

```cpp
21.456
-7.98
0.314159e1
3.14159e0
31.4159e-1
314.159e-2
```

普通浮点常量默认按 `double` 处理；数字后加 `F` 或 `f` 表示 `float`，例如 `1234F`。

### 字符常量和字符串常量

字符常量用单引号括住一个字符：

```cpp
'a'  '#'  '%'  'D'
```

字符常量区分大小写。`'a'` 和 `'A'` 是两个不同的字符常量。

字符串常量用双引号：

```cpp
"abcd"  "Hello!"  "Li-ping"
```

系统会自动在字符串末尾加入 `'\0'` 作为结束标志。因此 `"a"` 和 `'a'` 不同，前者通常占两个字节，后者占一个字节。

常用转义字符包括 `'\n'`、`'\t'`、`'\0'`、反斜杠和引号转义。

## 4. 符号常量与常变量

符号常量使用预处理命令：

```cpp
#define PI 3.1415926
#define WEIGHT 85
```

常变量使用 `const`：

```cpp
const double PI = 3.1415926;
const int WEIGHT = 85;
```

共同点：

- 都用标识符代表常量。
- 都要求先定义后使用。
- 都便于阅读、理解和修改。

区别：

- 符号常量没有类型，内存中没有与符号常量名对应的存储单元。
- 常变量具备变量特征，有类型和存储单元，但值不能修改。

## 5. 运算符和表达式

课件把 C++ 运算符大致分为 15 类，包括：

1. 算术运算符：`+ - * / % ++ --`。
2. 关系运算符：`> < == >= <= !=`。
3. 逻辑运算符：`&& || !`。
4. 位运算符：`<< >> & | ^ ~`。
5. 赋值运算符：`=` 及其扩展形式。
6. 条件运算符：`?:`。
7. 逗号运算符：`,`。
8. 指针运算符、引用与地址运算符。
9. `sizeof`、强制类型转换、成员运算符、下标和函数调用等。

表达式求值要考虑优先级和结合性。算术运算符通常左结合，赋值运算符右结合。在难以确定时可加括号。

## 6. 算术运算与赋值

整数除法和取余：

```cpp
5 / 3   // 整数除法，结果为 1
7 % 4   // 结果为 3
```

`%` 两侧都必须是整型数据。

赋值表达式一般形式：

```cpp
变量 = 表达式;
```

赋值号左边必须是可修改的左值。

左值：

- 变量可以作为左值。
- 常数不能作为左值。
- `a + b` 这类表达式不能作为左值。
- 常变量不能作为左值。

例子：

```cpp
3.1415926 = pi;   // 错：左边是常数
x + y = z;        // 错：左边是表达式
const int N=30;
N = 40;           // 错：常变量不能修改
```

## 7. 自增和自减

`++` 和 `--` 是单目运算符，运算数只能是变量。

```cpp
int a=7;
++a;  // 写法应理解为 ++a，a 变为 8
a++;   // a 变为 8
```

前缀和后缀的差别：

```cpp
int a=7,b;
b = ++a; // a=8,b=8
a = 7;
b = a++; // a=8,b=7
```

`++`、`--` 的结合方向为自右至左。一个表达式中多次修改同一变量容易产生歧义，应避免写出 `(i++)+(i++)+(i++)` 这类代码。

## 8. 关系、逻辑和逗号表达式

关系运算符优先级：

```text
(<, <=, >, >=)  高于  (==, !=)
```

逻辑运算符优先级：

```text
!  高于  &&  高于  ||
```

整体优先级可记为：

```text
! > 算术 > 关系 > &&、|| > 赋值
```

逗号表达式的求解顺序是从左到右，整个表达式的值为最后一个表达式的值。

```cpp
a = 3*5, a*4; // 先令 a=15，再求 a*4，整个逗号表达式值为 60
```

逗号运算符优先级最低。

## 9. sizeof 和类型转换

`sizeof` 用于计算类型或变量占用的字节数：

```cpp
sizeof(int)
sizeof(float)
sizeof x
sizeof(x)
```

赋值时可能发生类型转换：

- 浮点赋给整型：舍弃小数部分。
- 整型赋给浮点：数值不变，以浮点形式存储。
- 双精度赋给单精度：要注意范围，可能溢出。
- 字符赋给整型：赋入字符的 ASCII 码。
- 长整型赋给字符型：只保留低位，可能截断。
- 有符号赋给同长度无符号：存储内容原样搬移。

强制类型转换：

```cpp
(int)(x+y)
float(5%3)
(double)a
```

强制转换不改变原变量的类型和值。

## 10. 一维数组

数组是多个同类型数据对象的组合。

定义数组时要说明：

1. 元素类型。
2. 数组元素个数。

```cpp
int a[10];
double a1[100];
```

数组大小必须固定，不能依赖运行时输入的变量：

```cpp
int n;
cin >> n;
int a[n]; // 课件中列为错误写法
```

初始化：

```cpp
int a[4] = {1,1,2,4};
int b[4] = {1,2};
int c[] = {1,2,3,4,5,6,7,8};
```

部分初始化时，未给出的元素会自动初始化为 `0`。

下标从 `0` 到 `n-1`：

```cpp
int a[10];
// a[0] 到 a[9]
```

编译器通常不检查下标越界，程序员必须保证下标合法。

## 11. 字符数组和输入输出

字符数组：

```cpp
char str[10];
char str[8] = "program";
char c[10] = {'I',' ','a','m',' ','h','a','p','p','y'};
```

字符串末尾有 `'\0'`。输出字符数组时，`cout` 会一直输出到 `'\0'` 前。

基本输入输出：

```cpp
cin >> 变量;
cout << 表达式;
```

字符输入：

```cpp
char c1,c2,c3;
cin >> c1 >> c2 >> c3;
```

`cin >>` 按空白分隔读取；`cin.get()` 可读取包括空格和回车在内的任意字符；`cin.getline(数组名, 最大个数)` 读到换行前，第二参数包含字符串结束符。

## 12. 易错点

1. 未初始化变量当成 `0` 使用。
2. 变量名包含点、`#`、`$`、空格或以数字开头。
3. 混淆 `'a'` 和 `"a"`。
4. 把符号常量和常变量视为完全相同。
5. 混淆整数除法和浮点除法。
6. 在同一表达式中多次使用 `i++`。
7. 数组下标从 `1` 开始使用。
8. 用 `cin >>` 读取整行含空格的字符串。
9. 忽略字符数组末尾的 `'\0'`。
