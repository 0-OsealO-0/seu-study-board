## 1. 矩阵乘法的基本性质

设 `k` 是数，`A`、`B`、`C` 是矩阵。若等式的一边有意义，则另一边也有意义，并且等式成立。

### 结合律

`(AB)C = A(BC)`

结合律的价值在于：连乘时可以改变相邻因子的分组，但不能任意交换因子的位置。

### 分配律

`A(B + C) = AB + AC`

`(A + B)C = AC + BC`

使用分配律时，先确认加法中的矩阵同型，再确认各项乘法满足列数与行数匹配。

### 数乘与矩阵乘法的相容性

`(kA)B = k(AB) = A(kB)`

数 `k` 可以从任意一个因子旁边提出，但不能因此把矩阵乘法当成可交换乘法。

### 连乘积有意义的条件

若 `A1A2, A2A3, ..., A(s-1)As` 都有意义，则连乘积

`A1A2...As`

也有意义。对所有相邻因子都满足“左矩阵列数等于右矩阵行数”这个条件。

## 2. 方阵的幂

只有方阵才能定义正整数次幂。设 `A` 是方阵：

`A^1 = A`

`A^2 = AA`

`A^k = AA...A`，其中右边有 `k` 个因子 `A`。

对任意正整数 `k, l`：

`A^k A^l = A^(k+l)`

`(A^k)^l = A^(kl)`

指数相加和指数相乘成立，是因为这些幂都来自同一个矩阵 `A`。

## 3. 两个同阶方阵乘积的幂

若 `A`、`B` 是同阶方阵，并且 `AB = BA`，则对任意正整数 `k`：

`(AB)^k = A^k B^k`

当 `k = 2` 时：

`(AB)^2 = (AB)(AB) = A(BA)B = A(AB)B = A^2 B^2`

关键条件是 `AB = BA`。不能把这个公式无条件用于普通矩阵，因为矩阵乘法一般不可交换。

## 4. 四个网页的转移矩阵

第 4 页用四个网页构成的网络说明矩阵幂的意义。

若 `a_ij` 表示从网页 `j` 一步跳到网页 `i` 的概率，则两步转移概率为：

`b_ij = sum_k a_ik a_kj`

因此两步转移矩阵 `B` 等于一步转移矩阵的平方：

`B = A^2`

给出的

`A = [[0.4, 0.6, 0, 0.3], [0.2, 0.4, 0.6, 0], [0.2, 0, 0.4, 0.3], [0.2, 0, 0, 0.4]]`

对应

`A^2 = [[0.34, 0.48, 0.36, 0.24], [0.28, 0.28, 0.48, 0.24], [0.22, 0.12, 0.16, 0.30], [0.16, 0.12, 0, 0.22]]`

课件只提出问题 `B = ?`，上述矩阵由该页的一步转移矩阵按矩阵乘法补算。

## 5. 例 1：不可交换时，乘积幂不能拆开

设

`A = [[1, 1], [0, 0]]`，`B = [[1, 0], [1, 0]]`

计算得：

`AB = [[2, 0], [0, 0]]`

`BA = [[1, 1], [1, 1]]`

`(AB)^2 = [[4, 0], [0, 0]]`

`A^2 = A`，`B^2 = B`，`A^2 B^2 = AB = [[2, 0], [0, 0]]`

因为 `AB != BA`，所以 `(AB)^2 != A^2 B^2`。

## 6. 例 2：乘积不交换，但等式仍可能偶然成立

设

`A = [[0, 1], [0, 0]]`，`B = [[1, 0], [0, 0]]`

计算得：

`AB = O`

`BA = A`

`(AB)^2 = O`

`A^2 = O`，`B^2 = B`，`A^2 B^2 = O`

这里仍有 `AB != BA`，但 `(AB)^2 = A^2 B^2`。这说明不能只看某两个具体矩阵的结果，就断言一般公式成立或不成立。

## 7. 例 3：用结合律处理高次幂

设

`A = BC`

其中

`B = [[1], [2]]`，`C = [1, -1]`

则

`A = [[1, -1], [2, -2]]`

`CB = [1, -1][[1], [2]] = -1`

于是

`A^100 = (BC)(BC)...(BC)`

把中间的 `CB` 先结合：

`A^100 = B(CB)^99 C = B(-1)^99 C = -BC = -A`

所以

`A^100 = [[-1, 1], [-2, 2]]`

方法是先找一个可以反复结合的标量 `CB`，不要直接手算 100 次矩阵乘法。

## 8. 矩阵乘积与数乘的联系

第 10 页说明：

- `b` 乘 `n x 1` 矩阵属于矩阵数乘，结果是元素逐个乘 `b`。
- `1 x 1` 矩阵与 `n x 1` 矩阵相乘时，矩阵乘法退化为数乘。
- `b(a1, a2, ..., an) = (ba1, ba2, ..., ban)`。
- 形式相似不代表所有运算规律都相同；矩阵乘积仍要关注形状和交换性。

## 9. 易错点

1. 忘记矩阵乘法只在“左列数等于右行数”时有意义。
2. 把结合律误用为交换律，写成 `AB = BA` 或随意调换因子顺序。
3. 在 `AB != BA` 时仍使用 `(AB)^k = A^k B^k`。
4. 对方阵以外的矩阵写幂。
5. 看到某个具体例子中 `(AB)^2 = A^2 B^2`，就误以为无条件成立。
6. 遇到高次幂只做暴力乘法，没有先观察 `CB` 是否为标量或单位矩阵的倍数。
