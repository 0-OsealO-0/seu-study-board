## 一、Rⁿ 中向量的内积（第 2 页）

设 α = (a₁, a₂, …, aₙ)ᵀ，β = (b₁, b₂, …, bₙ)ᵀ，定义

$$\langle\alpha,\beta\rangle=a_1b_1+a_2b_2+\dots+a_nb_n=\sum_{i=1}^{n}a_ib_i=\alpha^{\mathsf T}\beta .$$

三条基本性质（逐条按分量验证）：

| 性质 | 内容 | 备注 |
| --- | --- | --- |
| 对称性 | ⟨α, β⟩ = ⟨β, α⟩ | 来自实数乘法的交换律 |
| 双线性 | ⟨aα + bβ, γ⟩ = a⟨α, γ⟩ + b⟨β, γ⟩；⟨γ, aα + bβ⟩ = a⟨γ, α⟩ + b⟨γ, β⟩ | 对两个位置都线性 |
| 正定性 | ⟨α, α⟩ ≥ 0，且 ⟨α, α⟩ = 0 ⇔ α = 0 | ⟨α, α⟩ = a₁² + a₂² + … + aₙ²，平方和 |

> 易错：⟨α, β⟩ 是**数**（1×1），αβᵀ 是 n×n 矩阵；αᵀβ 是内积，αβᵀ 不是。

## 二、向量的长度（第 3 页）

$$\|\alpha\|=\sqrt{\langle\alpha,\alpha\rangle}=\sqrt{a_1^2+a_2^2+\dots+a_n^2}.$$

若 ‖α‖ = 1，称 α 为**单位向量**。第 3 页的三条注：

1. ‖kα‖ = |k|·‖α‖（k 的绝对值，别漏）；
2. α ≠ 0 ⇒ ‖α‖ ≠ 0，令 ε = α / ‖α‖，则 ‖ε‖ = 1，称为把 α **单位化**（方向不变，长度变 1）；
3. ‖α‖² = ⟨α, α⟩（把长度问题化回内积问题，后面证明全靠它）。

补充：‖α − β‖ 就是两点 α、β 之间的距离。

## 三、Cauchy 不等式与三角不等式

### 1. 定理 1（Cauchy 不等式，第 4–5 页）

设 α, β ∈ Rⁿ，则

1. |⟨α, β⟩| ≤ ‖α‖·‖β‖；
2. |⟨α, β⟩| = ‖α‖·‖β‖ ⇔ α, β 线性相关。

**证明 (1)**：不妨设 α ≠ 0。令 γ = β − xα（x 为任意实数），则

$$0\le\langle\gamma,\gamma\rangle=\langle\beta-x\alpha,\beta-x\alpha\rangle=\langle\alpha,\alpha\rangle x^2-2\langle\alpha,\beta\rangle x+\langle\beta,\beta\rangle .$$

这是关于 x 的二次式，恒非负 ⇒ 判别式

$$\Delta=(2\langle\alpha,\beta\rangle)^2-4\langle\alpha,\alpha\rangle\langle\beta,\beta\rangle\le 0,$$

即 ⟨α, β⟩² ≤ ‖α‖²‖β‖²，开方得 |⟨α, β⟩| ≤ ‖α‖‖β‖。

**证明 (2)**：

- 若 α, β 线性相关，β = kα：|⟨α, β⟩| = |k|⟨α, α⟩ = |k|‖α‖² = ‖α‖·‖kα‖ = ‖α‖‖β‖；
- 若 α, β 线性无关，则对任意 x 有 β − xα ≠ 0，上面的二次式恒 **> 0** ⇒ Δ < 0 ⇒ |⟨α, β⟩| < ‖α‖‖β‖。

### 2. 定理 2（三角不等式，第 6 页）

$$\|\alpha+\beta\|\le\|\alpha\|+\|\beta\| .$$

**证明**：‖α + β‖² = ⟨α + β, α + β⟩ = ‖α‖² + 2⟨α, β⟩ + ‖β‖² ≤ ‖α‖² + 2|⟨α, β⟩| + ‖β‖² ≤ ‖α‖² + 2‖α‖‖β‖ + ‖β‖² = (‖α‖ + ‖β‖)²。

> 关键：中间那步先放大成 |⟨α, β⟩|，再用 Cauchy 不等式换成 ‖α‖‖β‖。两步缺一不可。

## 四、夹角与正交（第 7 页）

设 α, β 为非零向量，称

$$\theta=\arccos\frac{\langle\alpha,\beta\rangle}{\|\alpha\|\|\beta\|}\in[0,\pi]$$

为 α 与 β 的**夹角**。Cauchy 不等式保证括号里的数落在 [−1, 1]，夹角才有定义。

若 ⟨α, β⟩ = 0，称 α 与 β **正交**，记 α ⊥ β。

**勾股定理（注）**：α ⊥ β ⇒ ‖α + β‖² = ⟨α + β, α + β⟩ = ‖α‖² + ⟨α, β⟩ + ⟨β, α⟩ + ‖β‖² = ‖α‖² + ‖β‖²。

> 易错：零向量与任何向量都正交（内积恒为 0），但「夹角」对零向量没有定义，因为分母 ‖α‖ = 0 不能除。

## 五、正交向量组与标准正交基

### 1. 定义（第 8 页）

Rⁿ 中一组**非零**向量 α₁, …, αₛ，若两两正交，则称为**正交向量组**。

- 基本单位向量组 e₁, …, eₙ 是 Rⁿ 的正交向量组；
- R³ 中 (1, 2, 1)ᵀ, (1, −1, 1)ᵀ, (1, 0, −1)ᵀ 两两内积为 0，也是正交向量组。

### 2. 定理 3（正交组必无关，第 9–10 页）

设 α₁, …, αₛ 是正交向量组，则它们线性无关。

**证明**：设 k₁α₁ + k₂α₂ + … + kₛαₛ = 0。两边与 αᵢ 作内积：

$$k_i\langle\alpha_i,\alpha_i\rangle=\langle k_1\alpha_1+\dots+k_s\alpha_s,\alpha_i\rangle=0 .$$

其中 ⟨αᵢ, αᵢ⟩ = ‖αᵢ‖² > 0（非零向量），故 kᵢ = 0，i = 1, …, s。

> 这条定理的意义：正交组自带「无关」，所以正交组里不会有多余向量，正交化才可能奏效。

### 3. 标准正交向量组与标准正交基（第 11–12 页）

若 α₁, …, αₛ 两两正交且都是单位向量，称其为**标准正交向量组**；特别地，若它还是向量空间 V 的一组基，则称为 V 的一组**标准正交基**。

- e₁, …, eₙ 是 Rⁿ 的一组标准正交基；
- 把第 8 页的例子单位化：η₁ = (1, 2, 1)ᵀ/√6，η₂ = (1, −1, 1)ᵀ/√3，η₃ = (1, 0, −1)ᵀ/√2，是 R³ 的一组标准正交基。

### 4. 例 1（第 13–14 页）：坐标就是内积

设 α₁, …, αₛ 是标准正交向量组，α = k₁α₁ + … + kₛαₛ，证明 kᵢ = ⟨α, αᵢ⟩。

**证明**：⟨α, αᵢ⟩ = ⟨k₁α₁ + … + kₛαₛ, αᵢ⟩ = kᵢ⟨αᵢ, αᵢ⟩ = kᵢ‖αᵢ‖² = kᵢ（因为 ‖αᵢ‖ = 1）。

> 这就是标准正交基的最大好处：**坐标 = 内积**，不用解方程组。非标准正交基求坐标必须解线性方程组。

## 六、Schmidt 正交化方法（第 15–17 页）

### 1. 引例（例 2，第 15 页）

α₁, α₂ 线性无关，求 k 使 α₁ ⊥ (α₂ + kα₁)。

**解**：α₁ ⊥ (α₂ + kα₁) ⇔ ⟨α₂ + kα₁, α₁⟩ = 0 ⇔ ⟨α₂, α₁⟩ + k⟨α₁, α₁⟩ = 0 ⇔ k = −⟨α₂, α₁⟩/⟨α₁, α₁⟩。

注：令 β₁ = α₁，β₂ = α₂ + kα₁ = α₂ − ⟨α₂, β₁⟩/⟨β₁, β₁⟩ β₁，则 {α₁, α₂} 与 {β₁, β₂} 等价，且 β₁ ⊥ β₂。这正是 Schmidt 的第一步。

### 2. 第二步（第 16 页）

α₁, α₂, α₃ 线性无关，令 β₁ = α₁，β₂ = α₂ + kβ₁，β₃ = α₃ + k₂β₂ + k₁β₁，要求 β₃ 与 β₁、β₂ 都正交：

- β₃ ⊥ β₁ ⇒ k₁ = −⟨α₃, β₁⟩/⟨β₁, β₁⟩；
- β₃ ⊥ β₂ ⇒ k₂ = −⟨α₃, β₂⟩/⟨β₂, β₂⟩。

### 3. 一般过程（第 17 页）

设 α₁, …, αₛ 线性无关，

$$\beta_1=\alpha_1,\qquad \beta_k=\alpha_k-\sum_{i=1}^{k-1}\frac{\langle\alpha_k,\beta_i\rangle}{\langle\beta_i,\beta_i\rangle}\beta_i\ (k=2,\dots,s),$$

再单位化 ηₖ = βₖ/‖βₖ‖。则 η₁, …, ηₛ 是与 α₁, …, αₛ 等价的**标准正交向量组**。

> 两个要点：① 每一步只减去前面**已正交化**的 βᵢ，系数是 ⟨αₖ, βᵢ⟩/⟨βᵢ, βᵢ⟩ 而不是 ⟨αₖ, βᵢ⟩/‖αₖ‖²；② 正交化之后必须**再单位化**才是标准正交组。

### 4. 定理 4（第 18、20 页）

每个非零向量空间都有标准正交基。

**证明**：取 V 的一组基 α₁, …, αₛ，经 Schmidt 正交化 + 单位化得与它等价的标准正交组 η₁, …, ηₛ，由「等价的两组向量组同为基」（第 19 页注④）知 η 组是 V 的基。

第 19 页注⑤：s 维空间 V 中任意 s 个线性无关的向量都能作 V 的基。

### 5. 例 3（第 21–22 页）：把平面的一组基变成标准正交基

V = {(x, y, z)ᵀ | x + 2y − 3z = 0}。先求基：x = −2y + 3z，故

$$V=\{(-2y+3z,\ y,\ z)^{\mathsf T}\}=\{y(-2,1,0)^{\mathsf T}+z(3,0,1)^{\mathsf T}\},$$

取 α₁ = (−2, 1, 0)ᵀ，α₂ = (3, 0, 1)ᵀ（yα₁ + zα₂ = 0 比第二、三分量得 y = z = 0，无关）。

Schmidt：

$$\beta_1=\alpha_1=(-2,1,0)^{\mathsf T},\qquad \beta_2=\alpha_2-\frac{\langle\alpha_2,\beta_1\rangle}{\langle\beta_1,\beta_1\rangle}\beta_1 .$$

⟨α₂, β₁⟩ = −6，⟨β₁, β₁⟩ = 5，故

$$\beta_2=(3,0,1)^{\mathsf T}+\frac{6}{5}(-2,1,0)^{\mathsf T}=\left(\tfrac{3}{5},\tfrac{6}{5},1\right)^{\mathsf T}.$$

单位化：

$$\eta_1=\frac{(-2,1,0)^{\mathsf T}}{\sqrt 5},\qquad \eta_2=\frac{(3,6,5)^{\mathsf T}}{\sqrt{70}}\quad\left(\|\beta_2\|=\tfrac{\sqrt{70}}{5}\right).$$

> 验算 η₁ ⊥ η₂：−6 + 6 + 0 = 0 ✓。写答案时保留分数形式 (3/5, 6/5, 1) 再乘 5 化为整数向量，不容易算错。

## 七、正交矩阵（第 23–33 页）

### 1. 定义（第 23 页）

若 n 阶实矩阵 Q 满足 QᵀQ = E（即 Q⁻¹ = Qᵀ），称 Q 为**正交矩阵**（正交阵）；称映射 f: Rⁿ → Rⁿ，α ↦ Qα 为 Rⁿ 上的**正交变换**。

### 2. 旋转与反射（第 23–26 页）

$$Q=\begin{pmatrix}\cos\theta&-\sin\theta\\ \sin\theta&\cos\theta\end{pmatrix},\qquad Q^{\mathsf T}Q=\begin{pmatrix}\cos^2\theta+\sin^2\theta&0\\0&\sin^2\theta+\cos^2\theta\end{pmatrix}=E,$$

把 α = (r cos θ₀, r sin θ₀)ᵀ 变成 (r cos(θ₀+θ), r sin(θ₀+θ))ᵀ —— 逆时针旋转 θ。而 diag(1, −1) 是关于 x 轴的反射，diag(−1, 1) 是关于 y 轴的反射，两者也都是正交阵。

### 3. 定理 5 与列向量刻画（第 27–28 页）

设 Q = (q₁, q₂, …, qₙ)，则

$$Q^{\mathsf T}Q=(q_i^{\mathsf T}q_j)_{ij},$$

故 Q 为正交阵 ⇔ q₁, …, qₙ 为标准正交向量组 ⇔ q₁, …, qₙ 为 Rⁿ 的一组标准正交基。

### 4. 正交阵的性质（第 28–33 页）

设 Q 为 n 阶正交阵：

1. |Q| = ±1。证明：|Q|² = |Qᵀ||Q| = |QᵀQ| = |E| = 1。
2. Q⁻¹ = Qᵀ 也是正交阵。证明：(Qᵀ)ᵀQᵀ = QQᵀ = E（由 QᵀQ = E 两边取转置即得 QQᵀ = E）。
3. A, B 同阶正交 ⇒ AB 正交。证明：(AB)ᵀ(AB) = BᵀAᵀAB = BᵀEB = BᵀB = E。
4. ⟨Qx, Qy⟩ = ⟨x, y⟩，∀x, y。证明：(Qx)ᵀ(Qy) = xᵀQᵀQy = xᵀEy = ⟨x, y⟩。即正交变换**保内积**（因而保夹角）。
5. ‖Qx‖ = ‖x‖，∀x。证明：‖Qx‖² = (Qx)ᵀ(Qx) = xᵀQᵀQx = xᵀx = ‖x‖²。即正交变换**保长度**。

> 易错：性质 1 只是**必要**条件，|Q| = ±1 推不出 Q 正交（如 [[1,1],[0,1]] 行列式为 1 但不是正交阵）。判断正交只认 QᵀQ = E 或列向量组标准正交。

## 八、本次课小结

1. 内积把几何（长度、夹角、正交）翻译成代数（平方和、内积为零）；三条性质里正定性最容易被忽略「等号情形」。
2. Cauchy 不等式是整套理论的支点：夹角定义、三角不等式、勾股定理都由它保证。
3. 正交组的价值在于「无关 + 坐标即内积」；Schmidt 正交化把任意一组基变成标准正交基，代价是计算量大、易算错系数。
4. 正交矩阵 = 列向量组标准正交 = 保内积、保长度的线性变换；六条性质的证明都从 QᵀQ = E 出发。
