## 一、极大无关组（第 2.4 节）

### 1. 定义

设 α1, …, αs 是一个向量组。取它的一个部分组 αi1, …, αir，若

1. αi1, …, αir **线性无关**；
2. 向量组中**任一**向量都能由 αi1, …, αir **线性表示**，

则称 αi1, …, αir 为这个向量组的一个**极大（线性）无关组**。

要点：「部分组」是定义硬前提，极大无关组必须从原组内部挑。

### 2. 四条注解

| 注解 | 内容 | 为什么 |
| --- | --- | --- |
| 注① | 前提是「部分组」 | e1=(1,0)ᵀ, e2=(0,1)ᵀ 线性无关、能表示 α1=(1,1)ᵀ, α2=(1,2)ᵀ, α3=(1,0)ᵀ，但 e1,e2 ∉ {α1,α2,α3}，故不是该组的极大无关组 |
| 注② | 条件 2 可改成「其余向量都能表示」 | αij 可由 1·αij + 0·… 表示，这部分恒成立 |
| 注③ | 原组与极大无关组**等价** | 一个方向是子组关系，另一个方向由条件 2 |
| 注④ | 极大无关组**不唯一** | α1=(1,1)ᵀ, α2=(2,1)ᵀ, α3=(1,0)ᵀ 有三个： (α1,α2)、(α1,α3)、(α2,α3) |

### 3. 定理 1（个数唯一）

同一向量组中任意两个极大无关组等价，所含向量个数都等于整个向量组的秩。

证明：设两组为 αi1,…,αir 与 αj1,…,αjt。两者都线性无关且都与原组等价，于是

$$r = r\{\alpha_{i1},\dots,\alpha_{ir}\} = r\{\alpha_1,\dots,\alpha_s\} = r\{\alpha_{j1},\dots,\alpha_{jt}\} = t.$$

### 4. 定理 2（存在性与刻画）

设向量组秩 r > 0，则

1. 组中**存在** αj1, …, αjr 构成极大无关组；
2. 组中**任意** r 个线性无关的向量 αi1, …, αir 都构成极大无关组。

证明 (1)：A = (α1, …, αs) 为 n×s 矩阵，r(A) = r > 0 ⇒ A 有 r 阶非零子式；该子式也是 (αj1,…,αjr) 的 r 阶非零子式 ⇒ r{αj1,…,αjr} = r，线性无关。对剩余 αj，由 r{αj1,…,αjr, αj} = r < r+1 知它相关 ⇒ αj 可由这组表示。

证明 (2)：αi1,…,αir 线性无关 ⇒ r{αi1,…,αir} = r ⇒ 其矩阵有 r 阶非零子式，也是 A 的子式，由 (1) 即得。另一种验证：用极大无关组 αj1,…,αjr 表示 αi1,…,αir, αi，共 r+1 个向量、个数超过秩 r，必相关 ⇒ αi 可表示。

### 5. 例 1（求极大无关组并写表示系数）

$$A=(\alpha_1,\dots,\alpha_5)=\begin{pmatrix}
2 & -1 & -1 & 1 & 2\\
1 & 1 & -2 & 1 & 4\\
4 & -6 & 2 & -2 & 4\\
3 & 6 & -9 & 7 & 9
\end{pmatrix}$$

初等行变换化为行最简形：

$$\begin{pmatrix}
1 & 0 & -1 & 0 & 4\\
0 & 1 & -1 & 0 & 3\\
0 & 0 & 0 & 1 & -3\\
0 & 0 & 0 & 0 & 0
\end{pmatrix}$$

主元在第 1、2、4 列 ⇒ **α1, α2, α4 是一组极大无关组**，秩 = 3。列间线性关系不变，故

- α3 = −α1 − α2（系数取行最简形第 3 列）
- α5 = 4α1 + 3α2 − 3α4（系数取第 5 列）

要写系数时也可把 (α1, α2, α4, α3) 并成一列做行变换，解出 x = (−1, −1, 0)ᵀ。

注意：行变换只给出**系数**，极大无关组必须回到原矩阵取对应的列。

### 6. 例 2（循环差型，B = AC）

设 α1, α2, α3 线性无关，β1 = α1 − α2，β2 = α2 − α3，β3 = α3 − α1。令

$$A=(\alpha_1,\alpha_2,\alpha_3),\quad B=(\beta_1,\beta_2,\beta_3)=AC,\quad C=\begin{pmatrix}1&0&-1\\-1&1&0\\0&-1&1\end{pmatrix}$$

C 的三行之和为零、前两行不成比例 ⇒ r(C) = 2；故 r(B) ≤ r(C) = 2。又 β1, β2 的系数矩阵 (γ1, γ2) 满足 r(γ1,γ2) = 2，**A 可逆**时 r(A(γ1,γ2)) = r(γ1,γ2) = 2，所以 r(β1,β2) = 2，从而 β1, β2 是 β1, β2, β3 的一个极大无关组（秩 = 2）。

> 关键：由 r(AC) ≤ r(C) 只能得到上界；要把它变成等式，必须用「A 可逆（列满秩）时左乘不改变列秩」。

## 二、向量空间、基与维数（第 2.5 节）

### 1. 四个引例

1. Rⁿ = {(a1,…,an)ᵀ | ai ∈ R}：非空，加法与数乘结果仍在 Rⁿ；
2. 齐次方程解集 S = {x ∈ Rⁿ | Ax = 0}：A(ξ+η) = Aξ + Aη = 0，A(kξ) = kAξ = 0；
3. 生成集 S = {k1α1 + … + ksαs | ki ∈ R}：加法 (k1+l1)α1 + …，数乘 l(k1α1 + …) = (lk1)α1 + …；
4. 列空间 S = {Ax | x ∈ Rˢ}：Ax + Ay = A(x+y)，k(Ax) = A(kx)。

### 2. 子空间（向量空间）的定义

设 S 是 Rⁿ 的非空子集，若对任意 α, β ∈ S、k ∈ R 有 α + β ∈ S、kα ∈ S（对加法与数乘封闭），则称 S 为 Rⁿ 的一个**向量空间**（子空间）。

- 平凡子空间：{0} 与 Rⁿ。
- 核空间 K(A) = {x ∈ Rⁿ | Ax = 0}（Ax = 0 的解空间）。
- 生成子空间 L(α1,…,αs) = {k1α1 + … + ksαs | ki ∈ R}。
- 若 A = (α1,…,αs)，则 Ax = x1α1 + … + xsαs，于是 **L(α1,…,αs) = {Ax | x ∈ Rˢ} = R(A)**（列空间/值域）。

### 3. 非齐次解集不是向量空间

S = {x | Ax = b}，b ≠ 0：

- 无解时 S = ∅，非空都不满足；
- 有解时 A(x+y) = 2b ≠ b，A(3x) = 3b ≠ b，加法与数乘都不封闭。

对照：齐次 Ax = 0 的解集是子空间，且可写基础解系 ξ1,…,ξs（线性无关，任一 ξ 可由其表示），通解 ξ = k1ξ1 + … + ksξs。

### 4. 基与维数

称 α1,…,αs 为 V 的一组**基**，若 (1) 线性无关；(2) V 中任一向量都能由它们线性表示；此时 s 称为 V 的**维数**，dimV = s。

- 两组基都无关且都表示 V 中一切 ⇒ 互相等价 ⇒ 个数相同 ⇒ 维数与基的选择无关。
- dim{0} = 0（零空间没有非零向量可作基）。
- e1,…,en 是 Rⁿ 的基，dim Rⁿ = n。
- 若 α1,…,αs 是 V 的基，β1,…,βs 与它等价，则 β1,…,βs 也是 V 的基（秩相等 ⇒ 无关；表示关系传递 ⇒ 能表示一切）。
- s 维空间 V 中任意 s 个线性无关的向量都是基：若某个 α 不能由 β 组表示，则 β1,…,βs,α 线性无关，但 s+1 > dimV，矛盾。

### 5. 极大无关组给出基（定理）

若 αi1,…,αir 是 α1,…,αs 的一个极大无关组，则它是 V = L(α1,…,αs) 的一组基，且 dim L(α1,…,αs) = r{α1,…,αs}。于是「求生成子空间的基」＝「求向量组的极大无关组」。

### 6. 例 1（平面作子空间的基）

V = {(x,y,z)ᵀ | x + 2y − 3z = 0}。由 x = −2y + 3z 得

$$V=\{(-2y+3z,\ y,\ z)^{\mathsf T}\mid y,z\in\mathbb R\}=y(-2,1,0)^{\mathsf T}+z(3,0,1)^{\mathsf T}.$$

取 α1 = (−2,1,0)ᵀ, α2 = (3,0,1)ᵀ：若 yα1 + zα2 = 0，比第二、三分量得 y = z = 0，故无关；V 中向量都能写成它们的组合 ⇒ 是一组基，dimV = 2。

### 7. 例 2（求列空间的基与维数）

$$A=(\alpha_1,\alpha_2,\alpha_3,\alpha_4)=\begin{pmatrix}1&2&1&-1\\0&-1&-1&1\\-1&0&1&-1\end{pmatrix}$$

行变换得行最简形

$$\begin{pmatrix}1&0&-1&1\\0&1&1&-1\\0&0&0&0\end{pmatrix}$$

主元在第 1、2 列 ⇒ α1, α2 是一组基，dim L(α1,…,α4) = r(A) = 2。

## 三、坐标、过渡矩阵与坐标变换（第 2.6 节）

### 1. 坐标

设 α1,…,αs 是 V 的基，α ∈ V，则存在**唯一**的有序数组 k1,…,ks 使 α = k1α1 + … + ksαs，称 (k1,…,ks)ᵀ 为 α 在该基下的**坐标**。

唯一性：若还有 α = l1α1 + … + lsαs，相减得 (k1−l1)α1 + … + (ks−ls)αs = 0，由无关得 ki = li。

例：R³ 中 (a,b,c)ᵀ = ae1 + be2 + ce3，故它在 e1,e2,e3 下的坐标为 (a,b,c)ᵀ。

### 2. 过渡矩阵

设 α1,…,αs 与 β1,…,βs 是 V 的两组基，A = (α1,…,αs)，B = (β1,…,βs)。若

$$B=AC,\qquad (\beta_1,\dots,\beta_s)=(\alpha_1,\dots,\alpha_s)C,$$

则称 C 为从 α1,…,αs 到 β1,…,βs 的**过渡矩阵**。

- 回忆：(γ1,…,γn) = (α1,…,αs)B 时 γj = b1jα1 + … + bsjαs，即 C 的列向量组能由 A 的列向量组表示。
- 可逆性：s = 秩(B) ≤ 秩(C) ≤ s ⇒ 秩(C) = s ⇒ C 可逆，且 A = BC⁻¹，即从 β 基到 α 基的过渡矩阵是 **C⁻¹**。

### 3. 例 3（求过渡矩阵）

R³ 中 e1=(1,0,0)ᵀ, e2=(0,1,0)ᵀ, e3=(0,0,1)ᵀ 与 ε1=(1,0,1)ᵀ, ε2=(1,1,0)ᵀ, ε3=(1,1,1)ᵀ。

按 C 的第 j 列 = εj 在 e 基下的坐标：

$$C=\begin{pmatrix}1&1&1\\0&1&1\\1&0&1\end{pmatrix},\qquad C^{-1}=\begin{pmatrix}1&-1&0\\1&0&-1\\-1&1&1\end{pmatrix}.$$

从 ε 基到 e 基的过渡矩阵是 C⁻¹（不是 C）。

### 4. 坐标变换公式

η 在 α 基下坐标为 x、在 β 基下坐标为 y，则

$$\eta=(\alpha_1,\dots,\alpha_s)x=(\beta_1,\dots,\beta_s)y=(\alpha_1,\dots,\alpha_s)Cy\ \Rightarrow\ x=Cy,\qquad y=C^{-1}x.$$

### 5. 例 4

R³ 中 η = (a,b,c)ᵀ 在 ε1, ε2, ε3 下的坐标为

$$y=C^{-1}x=(a-b,\ a-c,\ -a+b+c)^{\mathsf T}.$$

验算：η = (1,2,3)ᵀ 时 y = (−1,−2,4)，而 −ε1 − 2ε2 + 4ε3 = (1,2,3)ᵀ，正确。

## 四、易错点清单

1. 极大无关组必须是**原组的子组**，不能从组外找更「标准」的向量（注① 的反例就是考点）。
2. 行变换得到的是**系数**，极大无关组要回原矩阵取主元列的原始向量。
3. 由 r(AC) ≤ r(C) 只能得**上界**，要得到等式必须有「A 可逆/列满秩」。
4. 非齐次解集不是子空间：无解是空集，有解时 A(x+y) = 2b。
5. dim{0} = 0，不要写成 1。
6. 过渡矩阵方向：B = AC 时 C 是 α→β；从 β 坐标换到 α 坐标乘 C⁻¹，别乘反。
7. 「任意 s 个线性无关向量都是基」只对 **s 维**空间成立（个数正好等于维数）。
