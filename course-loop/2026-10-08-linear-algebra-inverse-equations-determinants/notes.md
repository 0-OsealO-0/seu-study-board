## 1. 用初等变换求逆矩阵

回忆两个判定：

1. 矩阵 `A` 可逆当且仅当 `A` 可以写成一些初等矩阵的乘积。
2. 矩阵 `A` 可逆当且仅当 `A` 可经初等行变换化为单位矩阵 `E`。

如果

`Ps ... P2 P1 A = E`，

两边左乘得到

`A^-1 = Ps ... P2 P1`。

### 行变换法

对增广矩阵 `(A, E)` 做初等行变换：

`(A, E) -> ... -> (E, A^-1)`。

最终从右边的块读出 `A^-1`。

### 列变换法

把 `A` 与 `E` 上下排列：

```text
[ A ]   初等列变换   [  E  ]
[ E ]  ----------->  [ A^-1]
```

最终从下方的块读出 `A^-1`。

## 2. 用初等变换解矩阵方程

### 2.1 AX=B

设 `A` 为 `n` 阶可逆矩阵，`B` 为 `n x s` 矩阵，则

`AX = B`

有唯一解

`X = A^-1 B`。

用行变换：

`(A, B) -> ... -> (E, A^-1 B)`。

### 2.2 XA=B

设 `A` 为 `n` 阶可逆矩阵，`B` 为 `m x n` 矩阵，则

`XA = B`

有唯一解

`X = B A^-1`。

用列变换：

```text
[ A ]   初等列变换   [  E  ]
[ B ]  ----------->  [ B A^-1]
```

也可以用转置把 `XA=B` 化为

`A^T X^T = B^T`，

再用行变换法求 `X^T`。

### 2.3 为什么不能随意乘 A^-1

解 `AX=B` 时，一般不能在两边同时右乘 `A^-1`：

- 当 `n != s` 时，`B` 是 `n x s`，`A^-1` 是 `n x n`，`B A^-1` 一般无意义。
- 当 `n = s` 时，`B A^-1` 有意义，但 `X` 与 `AXA^-1` 未必相等，因为矩阵乘法一般不满足交换律。

解 `XA=B` 时同理，不能随意左乘 `A^-1`。

### 2.4 课堂例题

设

`A = [[0, 0, 1], [0, -1, 0], [1, 3, 0]]`，

则

`A^-1 = [[0, 3, 1], [0, -1, 0], [1, 0, 0]]`。

若

`B = [[1, 0], [2, -1], [3, 2]]`，

解 `AX=B` 得到

`X = [[9, -1], [-2, 1], [1, 0]]`。

若

`B = [[1, 2, 3], [0, -1, 2]]`，

解 `XA=B` 得到

`X = [[3, 1, 1], [2, 1, 0]]`。

## 3. 行列式的定义

### 3.1 二阶行列式

```text
| a11  a12 |
| a21  a22 | = a11 a22 - a12 a21
```

### 3.2 三阶行列式

三阶行列式可用对角线法则展开：

```text
| a11  a12  a13 |
| a21  a22  a23 |
| a31  a32  a33 |

= a11 a22 a33 + a12 a23 a31 + a13 a21 a32
  - a11 a23 a32 - a12 a21 a33 - a13 a22 a31
```

二阶、三阶行列式适合对角线法则，但四阶及四阶以上的行列式一般不适合。

### 3.3 余子式与代数余子式

在 `n` 阶行列式中，删去元素 `a_ij` 所在的第 `i` 行和第 `j` 列，余下的 `n-1` 阶行列式称为 `a_ij` 的余子式，记作

`M_ij`。

称

`A_ij = (-1)^(i+j) M_ij`

为 `a_ij` 的代数余子式。

### 3.4 n 阶行列式的递归定义

当 `n = 1` 时，

`D = a11`。

当 `n >= 2` 时，假设 `n-1` 阶行列式已经定义，则

`D = a11 A11 + a12 A12 + ... + a1n A1n`

即

`D = sum_{k=1}^n a1k A1k`。

这个公式称为 `|A|` 按第一行的展开式。

若方阵

`A = (a_ij)`

是 `n` 阶矩阵，则由它的元素构成的行列式记作

`det A` 或 `|A|`。

## 4. 行列式的计算

### 4.1 三阶行列式例题

计算

```text
      | 3  -1   2 |
D =   | 1   2  -1 |
      | 2   1   4 |
```

用对角线法则：

```text
D = 3 x 2 x 4 + (-1) x (-1) x 2 + 2 x 1 x 1
    - 3 x (-1) x 1 - (-1) x 1 x 4 - 2 x 2 x 2
  = 27
```

按第一行展开也会得到相同结果。

### 4.2 三角形行列式

上三角行列式和下三角行列式都等于主对角线元素的乘积：

`D_n = a11 a22 ... ann`。

证明方法是按第一行展开，并使用数学归纳法。

例如：

```text
| 2   0   0   0 |
|-1   3   0   0 |
| 4   5  -2   0 |
| 1   6   7   1 |

= 2 x 3 x (-2) x 1 = -12
```

## 5. 易错点

1. 做初等行变换时只处理左侧矩阵，忘记同步处理右侧的 `E` 或 `B`。
2. 混淆 `(A,E)` 行变换求逆与上下排列的列变换求逆。
3. 矩阵方程两边乘 `A^-1` 时不检查维数和乘法顺序。
4. 混淆 `AX=B` 的解 `X=A^-1B` 与 `XA=B` 的解 `X=BA^-1`。
5. 计算代数余子式时漏掉 `(-1)^(i+j)`。
6. 对四阶及以上行列式误用对角线法则。
7. 把余子式 `M_ij` 与代数余子式 `A_ij` 混为一谈。
