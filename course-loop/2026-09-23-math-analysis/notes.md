## 1. 数列

数列是从正整数集到实数集的函数，通常记作 `{a_n}`。

`a_n` 表示第 `n` 项；`{a_n}` 表示由所有项组成的整个数列。

## 2. 数列极限的 epsilon-N 定义

若对任意 `epsilon > 0`，都存在正整数 `N`，使得当 `n > N` 时都有

`|a_n - a| < epsilon`

则称数列 `{a_n}` 收敛于 `a`，记作

`lim(n -> infinity) a_n = a`

定义中的量词顺序是：

1. 任给 `epsilon > 0`
2. 存在正整数 `N`
3. 对任意 `n > N`

`N` 可以依赖 `epsilon`，但不能依赖某个具体的 `n`。一旦选定 `N`，就必须控制它后面的所有项。

## 3. 邻域解释

`|a_n - a| < epsilon` 等价于

`a - epsilon < a_n < a + epsilon`

也就是说，`a_n` 落在点 `a` 的 `epsilon` 邻域中。

数列收敛于 `a` 表示：任意给定 `a` 的一个邻域，数列从某一项开始的所有项都落在该邻域内。前面有限多个项不影响极限。

## 4. 收敛与发散

- 若存在有限实数 `a`，使 `lim a_n = a`，则称数列收敛。
- 若不存在这样的有限实数 `a`，则称数列发散。
- 发散不一定意味着趋于正无穷或负无穷；例如 `(-1)^n` 发散，但不趋于无穷。

## 5. 用定义证明极限的步骤

1. 先化简并估计 `|a_n - a|`
2. 任给 `epsilon > 0`
3. 根据误差估计解出或放缩得到 `n > N` 的充分条件
4. 取满足条件的正整数 `N`
5. 对任意 `n > N` 验证 `|a_n - a| < epsilon`
6. 按定义写出极限结论

## 6. 典型证明

### 例 1：证明 `lim 1/n = 0`

任给 `epsilon > 0`，取 `N > 1/epsilon`。

当 `n > N` 时：

`|1/n - 0| = 1/n < 1/N < epsilon`

所以 `lim 1/n = 0`。

### 例 2：证明 `lim (2n + 1)/(n + 2) = 2`

先估计误差：

`|(2n + 1)/(n + 2) - 2| = 3/(n + 2) < 3/n`

任给 `epsilon > 0`，取 `N > 3/epsilon`。当 `n > N` 时，误差小于 `epsilon`。

### 例 3：证明 `lim (n + 3)/(2n + 1) = 1/2`

误差为：

`|(n + 3)/(2n + 1) - 1/2| = 5/[2(2n + 1)] < 5/(4n)`

任给 `epsilon > 0`，取 `N > 5/(4epsilon)`。当 `n > N` 时，误差小于 `epsilon`。

## 7. 两个重要性质

### 极限唯一性

若数列同时收敛于 `a` 和 `b`，则 `a = b`。

证明思路：分别把两项控制到极限的 `epsilon/2` 邻域内，再利用三角不等式：

`|a - b| <= |a - a_n| + |a_n - b| < epsilon`

因为 `|a - b|` 是非负常数，且对任意 `epsilon > 0` 都小于 `epsilon`，所以 `|a - b| = 0`。

### 收敛数列有界

设数列收敛于 `a`。取 `epsilon = 1`，则存在 `N`，使 `n > N` 时

`|a_n| < |a| + 1`

令

`M = max(|a_1|, ..., |a_N|, |a| + 1)`

则所有项都满足 `|a_n| <= M`。

有界数列不一定收敛，例如 `(-1)^n`。

## 8. 易错点

1. 把“存在正整数 `N`”写成“存在某个 `n`”
2. 找到 `N` 后漏写“对所有 `n > N`”
3. 让 `N` 依赖具体的 `n`
4. 放缩方向写反，或放缩后不能保证仍小于 `epsilon`
5. 用若干项的趋势代替无穷尾部的严格证明
6. 把发散与趋于无穷混为一谈
