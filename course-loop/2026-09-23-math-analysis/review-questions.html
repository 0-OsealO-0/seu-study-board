先独立作答，不查课件或答案。涉及极限定义的题必须写清 epsilon、N 以及 n > N 后的估计。本卷按“1.2.1 数列极限的定义”标准框架命题，收到课件后需核对标题与符号。
  1. 给出数列 {a_n} 的定义，并说明 a_n 与整个数列 {a_n} 的区别。
  2. 完整叙述 lim(n->infinity) a_n = a 的 epsilon-N 定义。
  3. 在极限定义中，epsilon 与 N 的先后顺序是什么？N 是否可以依赖 epsilon 或 n？
  4. 写出“数列 {a_n} 不收敛于 a”的否定命题。
  5. 用 epsilon-N 定义证明 lim(n->infinity) 1/n = 0。
  6. 用 epsilon-N 定义证明 lim(n->infinity) (2n+1)/(n+2) = 2。
  7. 证明常数列 a_n = c 收敛于 c。
  8. 用 epsilon-N 定义证明 lim(n->infinity) (n+3)/(2n+1) = 1/2。
  9. 用极限定义的否定形式说明数列 a_n = (-1)^n 不收敛。提示：分别考察 a = 1、a = -1 和 a 不等于 +/-1 的情形。
  10. 从邻域角度解释 lim(n->infinity) a_n = a 的含义，并说明为什么数列的有限多个前项不影响该极限。
  11. 证明收敛数列的极限唯一。
  12. 证明收敛数列一定有界。
