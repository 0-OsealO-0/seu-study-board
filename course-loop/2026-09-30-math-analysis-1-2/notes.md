## 1. 1.2.0 极限思想的两个实例

### 割圆术

刘徽割圆术用圆内接正多边形面积逼近圆面积。边数越大，正多边形面积越接近圆面积，最终把圆面积定义为这些面积的极限。

### 瞬时速度

物体在 `[t, t+Delta t]` 内的平均速度为

`v_avg = (s(t+Delta t)-s(t))/Delta t`。

当 `Delta t` 趋近于 0 时，平均速度的极限就是时刻 `t` 的瞬时速度。

两个实例共同体现了极限思想：先研究局部变化，再让控制变化的参数趋于某个值。

## 2. 数列的定义

数列是按正整数顺序排列的一列数：

`a1, a2, ..., an, ...`

记作 `{a_n}`。数列可以看成定义在正整数集 `N+` 上的函数：

`f(n) = a_n`。

数列中的项有顺序。`a_n` 表示第 `n` 项，`{a_n}` 表示整个数列，两者不同。

## 3. 数列极限的 epsilon-N 定义

设 `{a_n}` 是数列，`a` 是实数。若对任意 `epsilon>0`，总存在正整数 `N`，使当 `n>N` 时都有

`|a_n-a| < epsilon`，

则称数列 `{a_n}` 收敛于 `a`，记作

`lim(n->infinity) a_n = a`。

符号形式：

`forall epsilon>0, exists N in N+, forall n>N, |a_n-a|<epsilon`。

量词顺序关键：先任给 `epsilon>0`，再找一个 `N`，最后要求所有 `n>N` 的项都满足不等式。

`N` 可以依赖 `epsilon`，但不能依赖某个具体的 `n`。

邻域解释：任取 `a` 的邻域 `(a-epsilon,a+epsilon)`，数列从某项起的所有项都落在该邻域中。

## 4. 收敛、发散和定义否定

若存在有限实数 `a` 使 `lim a_n=a`，则数列收敛；否则称数列发散。发散不等于趋于无穷。

“`{a_n}` 不收敛于 `a`”的否定命题：

`exists epsilon_0>0, forall N, exists n>N, |a_n-a|>=epsilon_0`。

## 5. 用定义证明极限

基本流程：

1. 先化简并估计 `|a_n-a|`。
2. 任给 `epsilon>0`，根据估计解出或放缩得到 `n>N` 的充分条件。
3. 取满足条件的正整数 `N`。
4. 对任意 `n>N` 验证 `|a_n-a|<epsilon`。
5. 按定义写出结论。

### 例：`|q|<1` 时 `q^n -> 0`

若 `q=0`，显然。若 `0<|q|<1`，任给 `epsilon>0`，要使

`|q^n-0|=|q|^n<epsilon`，

可解出

`n > ln epsilon / ln |q|`。

取足够大的正整数 `N` 即可。

### 例：`sin n / n^2 -> 0`

利用 `|sin n|<=1`：

`|sin n/n^2-0| <= 1/n^2 < epsilon`。

取 `N=[1/sqrt(epsilon)]+1`，当 `n>N` 时成立。

### 例：`(n^2+1)/(2n^2-3n) -> 1/2`

先做误差估计：

`|(n^2+1)/(2n^2-3n)-1/2| = |(3n+2)/(2n(2n-3))|`。

对足够大的 `n` 可放缩为 `2/n`，再令 `2/n<epsilon` 选择 `N`。

## 6. 1.2.2 数列极限的性质

### 唯一性

若数列收敛，则极限唯一。

证明：设收敛于 `a`、`b`。任给 `epsilon>0`，当 `n` 足够大时，

`|a-b| <= |a-a_n| + |a_n-b| < epsilon`。

非负常数 `|a-b|` 对任意正数 `epsilon` 都小于 `epsilon`，故 `|a-b|=0`，即 `a=b`。

### 有界性

收敛数列必有界。

证明：设 `a_n->a`，取 `epsilon=1`，则足够后面的项满足 `|a_n|<|a|+1`。前有限项也有界，取所有前项绝对值和 `|a|+1` 的最大值即可。

有界数列不一定收敛，例如 `(-1)^n`。

### 保序性

若 `lim a_n=a`、`lim b_n=b`，且 `a<b`，则存在 `N`，使 `n>N` 时 `a_n<b_n`。

推论：若从某项起 `a_n<=b_n`，且两列都收敛，则 `a<=b`。不能推出严格不等式。

### 保号性

若 `lim a_n=a>0`，则存在 `N`，使 `n>N` 时 `a_n>a/2>0`。

若 `lim a_n=a<0`，则从某项起 `a_n<a/2<0`。

### 绝对值性质

若 `a_n->a`，则 `|a_n|->|a|`。

反之一般不成立，例如 `(-1)^n`。

### 四则运算

若 `a_n->a`、`b_n->b`，则

`alpha a_n + beta b_n -> alpha a + beta b`

`a_n b_n -> ab`

若 `b != 0` 且从某项起 `b_n != 0`，则

`a_n/b_n -> a/b`。

### 夹逼定理

若从某项起

`a_n <= b_n <= c_n`

且

`lim a_n = lim c_n = a`，

则 `lim b_n=a`。

### Stolz 公式

若 `{y_n}` 严格单调且趋于无穷，并且

`(x_n-x_(n-1))/(y_n-y_(n-1)) -> a`，

其中 `a` 可为有限数或无穷，则

`x_n/y_n -> a`。

## 7. 1.2.3 数列收敛的判别法

### 单调有界原理

单调增加且有上界的数列必收敛。

单调减少且有下界的数列必收敛。

递推数列常用步骤：

1. 用数学归纳法证明有界。
2. 证明单调。
3. 由单调有界原理得收敛。
4. 对递推式取极限，解出极限。

### 区间套定理

若闭区间列

`[a1,b1] contains [a2,b2] contains ...`

且

`lim(b_n-a_n)=0`，

则存在唯一实数 `xi` 属于所有这些区间，并且

`xi = lim a_n = lim b_n`。

### 子列判别

收敛数列的任意子列都收敛，并且极限相同。

特别地，

`lim a_n=a` 当且仅当奇子列与偶子列都收敛于 `a`。

### Bolzano-Weierstrass 定理

有界数列必有收敛子列。

证明可用逐次二分区间，构造长度趋于 0 的区间套，在每层选择一个包含数列中无穷多项的子区间，最后得到收敛子列。

### 无界数列

无界数列存在趋于无穷的子列。可依次选取满足 `|x_(n_k)|>k` 的项来构造。

### Cauchy 收敛准则

若对任意 `epsilon>0`，存在 `N`，使任意 `m,n>N` 都有

`|a_m-a_n|<epsilon`，

则称 `{a_n}` 为 Cauchy 数列。

实数数列收敛当且仅当它是 Cauchy 数列。

Cauchy 数列必有界。Cauchy 准则不需要预先知道极限，而是用数列自身项间距离判定收敛。

## 8. 定理联系

实数完备性、单调有界原理、区间套定理、Weierstrass 定理和 Cauchy 准则从不同角度刻画实数系的完备性。

典型依赖关系：

`实数完备性 -> 单调有界原理 -> 区间套定理 -> Weierstrass 定理 -> Cauchy 准则 -> 实数完备性`

## 9. 易错点

1. 把 `epsilon-N` 定义中的量词顺序写错。
2. 让 `N` 依赖 `n`。
3. 只验证有限项，而不是所有尾部项。
4. 把有界当成收敛。
5. 把 `|a_n|` 收敛误认为 `a_n` 收敛。
6. 保序时把 `a<=b` 推成 `a<b`。
7. 使用四则运算时忘记分母极限非零。
8. 使用单调有界原理时只证明单调或只证明有界。
9. 混淆构造子列与证明整个数列收敛。
10. 把 Cauchy 条件只当作计算方法，忽略它依赖实数完备性。
