  1. 叙述夹逼准则的完整条件，并说明为什么两端必须同阶、同极限。
  2. 用夹逼求 n 项和极限时，写出“项数 × 最小项”与“项数 × 最大项”两个标准界的完整不等式。
  3. 叙述单调有界准则，并说明为什么“先证有界、再证单调、最后取极限”的顺序不能颠倒。
  4. 证明数列单调的三种常用手段分别是什么？各适合什么结构？
  5. 已知 xₙ₊₁ = f(xₙ)，叙述用不动点法求极限的完整三步，并说明为什么最后要舍根。
  6. 叙述 Cauchy 收敛准则及其否定形式，并写出否定形式里 ε₀、n、m 三者的量词顺序。
  7. 证明 lim sin n 不存在，为什么不能只验证“某条子列不收敛”？应该怎么组织反证？
  8. 求 lim (1 − 1/2²)(1 − 1/3²)…(1 − 1/n²)。
  9. 求 lim [1/2 + 1/(2(1+2)) + … + 1/(2(1+2+…+n))]ⁿ。
  10. 设 x₁ = a/2，xₙ₊₁ = (a + xₙ²)/2，其中 0 < a ≤ 1。证明 {xₙ} 收敛并求 lim xₙ。
  11. 证明 lim (2n−1)!!/(2n)!! = 0（要求给出可求和或可夹逼的界）。
  12. 设 {xₙ} 是正数列且满足 2xₙ₊₁ + 1/xₙ² < 3。证明 {xₙ} 收敛并求 lim xₙ。
