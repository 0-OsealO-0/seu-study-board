## 1. 方阵的多项式

设 `A` 是 `n` 阶方阵，多项式

`f(x) = a_s x^s + a_(s-1) x^(s-1) + ... + a_1 x + a_0`

代入矩阵后定义为

`f(A) = a_s A^s + a_(s-1) A^(s-1) + ... + a_1 A + a_0 E`。

常数项 `a_0` 不能直接与矩阵相加，要乘同阶单位矩阵 `E`。

### 例 1

设

`A = [[1, 1], [0, 0]]`，`f(x) = x^2 + 2x - 3`。

因为 `A^2 = A`，所以

`f(A) = A + 2A - 3E = 3A - 3E`。

即

`f(A) = [[0, 3], [0, -3]]`。

## 2. 矩阵和与差的乘法展开

对同阶方阵 `A`、`B`：

`(A + B)^2 = A^2 + AB + BA + B^2`

`(A - B)^2 = A^2 - AB - BA + B^2`

`(A + B)(A - B) = A^2 - AB + BA - B^2`

在结果中必须保留 `AB` 与 `BA` 两项。只有当 `AB = BA` 时，交叉项才能合并。

### 二项展开

若 `A`、`B` 同阶且 `AB = BA`，则

`(A + B)^n = A^n + C(n,1) A^(n-1) B + ... + C(n,n-1) A B^(n-1) + B^n`

也可写成

`(A + B)^n = sum_(k=0)^n C(n,k) A^(n-k) B^k`。

## 3. 用二项展开计算矩阵的高次幂

设

`J = [[lambda, 1, 0], [0, lambda, 1], [0, 0, lambda]]`。

把 `J` 拆成

`A = [[lambda, 0, 0], [0, lambda, 0], [0, 0, lambda]] = lambda E`

和

`B = [[0, 1, 0], [0, 0, 1], [0, 0, 0]]`。

于是 `J = A + B`，且 `AB = BA`。同时

`A^n = lambda^n E`

`B^2 = [[0, 0, 1], [0, 0, 0], [0, 0, 0]]`

`B^3 = O`。

因此

`J^10 = A^10 + 10 A^9 B + 45 A^8 B^2`

`J^10 = [[lambda^10, 10 lambda^9, 45 lambda^8], [0, lambda^10, 10 lambda^9], [0, 0, lambda^10]]`。

关键步骤是寻找可交换的拆分 `J = A + B`，并利用 `B` 的高次幂最终化为零。

## 4. 同一个方阵的多项式可交换

设 `A` 为方阵，`f(x)`、`g(x)` 是多项式，令 `h(x) = f(x) g(x)`。则

`f(A)g(A) = h(A) = g(A)f(A)`。

原因是所有因式都是同一个矩阵 `A` 的幂，而 `A^k A^l = A^(k+l)`。

## 5. 结合律与高次幂

若 `A = BC`，并且中间乘积 `CB` 是标量矩阵或退化为一个数，就可利用

`A^n = (BC)^n = B(CB)^(n-1)C`

快速求幂。

在本节例子中

`B = [[1], [2]]`，`C = [1, -1]`

因此

`CB = [1, -1] [[1], [2]] = -1`

`A = BC = [[1, -1], [2, -2]]`

`A^100 = B(-1)^99 C = -BC = -A = [[-1, 1], [-2, 2]]`。

## 6. 关系矩阵的平方

在四位同学的关系矩阵例子中，矩阵元素定义为

`a_ij = 1` 表示第 `i` 号和第 `j` 号同学是微信好友；否则 `a_ij = 0`。

在无向好友关系下，`A` 是对称矩阵，并且通常主对角线元素为 `0`。

此时：

- `(A^2)_ii = sum_k a_ik a_ki = sum_k a_ik^2`，等于第 `i` 号同学的好友数。
- 当 `i != j` 时，`(A^2)_ij = sum_k a_ik a_kj`，等于第 `i` 号和第 `j` 号同学的共同好友数。

课件例子给出的

`A^2 = [[2, 1, 1, 1], [1, 3, 1, 0], [1, 1, 2, 1], [1, 0, 1, 1]]`

说明四人的好友数依次为 `2, 3, 2, 1`。其中 `b_23 = 1` 表示第 2 号和第 3 号同学有 1 个共同好友。

课件把选项 `②` 标为答案。严格按关系矩阵的定义，仅由 `A^2` 可知两人有共同好友，不能单独推出两人一定直接互为好友；若课堂还有额外条件，应以老师的完整题意和口径为准。

## 7. 矩阵的转置

把 `m x n` 矩阵 `A` 的行与列互换，得到的 `n x m` 矩阵称为 `A` 的转置，记作 `A^T`。

若 `A = (a_ij)`，则

`(A^T)_ij = a_ji`。

转置的基本性质：

`(A^T)^T = A`

`(A + B)^T = A^T + B^T`

`(kA)^T = kA^T`

`(AB)^T = B^T A^T`

最后一条称为反序律。对多个矩阵同样有

`(A_1 A_2 ... A_s)^T = A_s^T ... A_2^T A_1^T`。

### 对称矩阵与反对称矩阵

若 `A` 是方阵且

`A^T = A`，

则称 `A` 为对称矩阵，等价于对所有 `i, j` 都有 `a_ij = a_ji`。

若

`A^T = -A`，

则称 `A` 为反对称矩阵。在实数范围内，反对称矩阵的主对角线元素都为 `0`。

### 两个证明例子

1. 设 `B = A + A^T`，则

`B^T = (A + A^T)^T = A^T + A = B`，

所以 `B` 是对称矩阵。

2. 设 `B = A A^T`，则

`B^T = (A A^T)^T = (A^T)^T A^T = A A^T = B`，

所以 `B` 是对称矩阵。

## 8. 分块矩阵的基本概念

把矩阵用若干条横线和竖线划分成多个小矩阵，每个小矩阵称为子块。按子块排列得到的矩阵称为分块矩阵。

一般写成

`A = [[A_11, A_12, ..., A_1t], [A_21, A_22, ..., A_2t], ..., [A_s1, A_s2, ..., A_st]]`

其中 `A_ij` 是 `m_i x n_j` 矩阵。

同一块行的各子块有相同的行数，同一块列的各子块有相同的列数。

## 9. 常用的分块方法

### 分出特殊矩阵

例如把一个 `5 x 5` 矩阵分成

`A = [[E_3, B], [C, O_2]]`。

其中 `E_3` 是 3 阶单位矩阵，`O_2` 是 2 阶零矩阵。

### 分块对角矩阵

形如

`diag(A_1, A_2, ..., A_s) = [[A_1, O, ..., O], [O, A_2, ..., O], [..., ..., ..., ...], [O, O, ..., A_s]]`

的矩阵称为分块对角矩阵，其中各 `A_i` 都是方阵。

### 按列分块

按列划分时可写成

`A = (A_1, A_2, ..., A_n)`，

其中每个 `A_j` 是 `A` 的第 `j` 列。

### 按行分块

按行划分时可写成

`A = [[alpha_1], [alpha_2], [...], [alpha_m]]`，

其中每个 `alpha_i` 是 `A` 的第 `i` 行。

## 10. 分块矩阵的基本运算

### 分块加法

两个同型矩阵按相同方式分块后，对应子块相加：

`(A + B)_ij = A_ij + B_ij`。

### 分块数乘

数 `k` 分别乘每一个子块：

`(kA)_ij = kA_ij`。

### 分块乘法

设 `A` 为 `l x m` 矩阵，`B` 为 `m x n` 矩阵。将 `A`、`B` 分块，使所有 `A_ik B_kj` 都有意义，则

`AB = (C_ij)`，其中

`C_ij = sum_(k=1)^s A_ik B_kj`。

分块乘法形式上像普通矩阵乘法，但前提是内侧分块维数严格匹配，并且块乘法的顺序不能随意交换。

## 11. 易错点

1. 计算 `f(A)` 时把常数项 `a_0` 直接写成数，忘记乘单位矩阵 `E`。
2. 展开 `(A + B)^2` 时漏掉 `BA`，或把 `AB + BA` 直接合并成 `2AB`。
3. 未验证 `AB = BA` 就使用二项式定理。
4. 计算 `A^n = (BC)^n` 时没有利用可结合成标量的 `CB`。
5. 把 `A^2` 的非对角元素误认为两人直接好友的证据；它表示的是共同好友数。
6. 转置乘积时忘记反序，写成 `(AB)^T = A^T B^T`。
7. 分块时只检查外框同型，没有检查内部分块乘法是否匹配。
