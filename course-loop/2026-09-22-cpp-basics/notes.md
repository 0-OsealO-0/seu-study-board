## 2. 简单的 C++ 程序实例

第 3 页给出一个符合 ANSI C++ 语法的程序：

```cpp
// 源程序文件名为 ex1_1.cpp
#include <iostream> // 标准输入/输出头文件，预处理命令
using namespace std; // 使用命名空间 std

int main()
{
    cout << "This is a C++ program.";
    return 0;
}
```

关键点：

- C++ 标准库头文件建议不带 `.h`。
- C++ 标准库中的类和函数放在命名空间 `std` 中声明。
- `main` 函数返回 `int` 型数值。
- `return 0;` 通常表示程序正常结束。
- `cout << ...;` 用于标准输出。

第 4 页同时展示旧式 C++ 语法：

```cpp
#include <iostream.h>

void main()
{
    cout << "This is a C++ program.";
}
```

旧式写法的背景：

- 为了兼容 C 语言，保留了 C 风格头文件形式，例如 `iostream.h`。
- C 语言没有命名空间。
- C 语言不要求 `main` 返回整型数值。
- 有些旧版或少严格配置的编译器可能同时接受两种写法。
- 新版 C++ 编译系统应优先严格执行现代 C++ 标准。

本课应使用现代标准写法的骨架：

```cpp
#include <iostream>
using namespace std;

int main()
{
    return 0;
}
```

## 3. C++ 的词法单位

第 5-9 页将词法单位分为：

1. C++ 字符集。
2. 关键字。
3. 标识符。
4. 标点符号。

### 3.1 C++ 字符集

一个 C++ 程序可以看成由基本字符按规则组成的序列。课件列出的基本字符包括：

- 数字字符：`0-9`。
- 大小写拉丁字母：`a-z`、`A-Z`。
- 其他可打印字符：例如 `!`、`#`、`%`、`^`、`&`、`*`、`-`、`+`、`=`。
- 空白字符：空格符、换行符、制表符等。

### 3.2 关键字

关键字也称为保留字，是系统预先定义的标识符，具有特殊含义，不能用于其他目的。

课件给出的例子：

```text
double  int  private  public  static
```

### 3.3 标识符

标识符是 C++ 中用来标识函数、变量、符号常量、数组、类型、语句标号、文件等的有效字符序列。

标识符就是一个名字。第 8 页只给出概念，没有在本页展开完整的命名规则。

### 3.4 标点符号

课件列出的标点符号包括：

```text
#  (  )  {  }  ,  :  ;  "  '  ...
```

标点符号在程序中承担结构分隔、分组和语法作用，不能把中文全角符号与英文编程符号混用。

## 4. C++ 的数据类型

第 10 页给出数据类型的定义：

- 数据类型指定数据所代表的含义，以及可以对数据执行哪些操作。
- 数据类型是程序中最基本的元素。

C++ 的数据类型大体分为五种：

1. 基本类型。
2. 构造类型。
3. 指针类型。
4. 引用类型。
5. 空类型。

第 10 页只给出总分类，各类型的具体内容和取值范围在后续页面继续展开。

## 5. 课堂代码骨架的易错点

1. 把旧式 `#include <iostream.h>` 与现代 `#include <iostream>` 混用。
2. 忘记 `using namespace std;` 后直接使用标准库名字，又不写 `std::` 限定。
3. 把旧式 `void main()` 当成规范的新式 C++ 入口。
4. 遗漏 `main` 的 `int` 返回类型或 `return 0;`。
5. 把关键字当成自定义名字，例如用 `int`、`private` 给变量命名。
6. 混淆字符、字符串和标点符号的书写形式。
7. 把中文标点当成 C++ 标点。
8. 把“基本类型”等五种分类与实际的具体数据类型名称混为一谈。
