先独立作答，不查课件或答案。定义题要写全条件与反向是否成立；证明题要写清每一步乘的是哪个矩阵、为什么可以对系数下结论。
  1. 用向量组的秩写出线性相关与线性无关的定义，并解释为什么「秩小于向量个数」正好对应「相关」；再用 (1,0),(0,1) 与 (5,0),(0,0) 两组向量各判断一次。
  2. 完整叙述定理1、推论1、推论2，并写出定理1 的证明思路（说明用的是哪一种初等变换、得到的矩阵等式是什么、取哪个行向量作为系数）。
  3. 叙述并各给一句理由：向量组与其转置向量组的相关性关系；单个向量线性相关的充要条件；含零向量的向量组是否相关；两个向量线性相关与分量成比例的关系。
  4. 判断 s 个 n 维向量什么时候必然线性相关；叙述拼接（接长）与截短之间的结论及其逆否形式；说明「多的能由少的表示」为什么导致相关；由此推出两个线性无关且等价的向量组的个数有什么关系。
  5. 叙述定理2 与定理3，并明确指出定理2 中「存在某个」与「每一个」的区别，以及定理3 的两个前提条件缺一会怎样。
  6. 设 α1..αs 线性无关，β_j = c_1j α1 + … + c_sj αs（j=1..s），C=(c_ij)，B=(β1..βs)。写出 B 与 A、C 的关系，说明为什么 β 组线性无关当且仅当 C 可逆，并解释只用 r(AC) ≤ r(C) 能不能完成这一步。
  7. 证明：若 α 组线性相关、s>1 且 α1≠0，则存在 j（2 ≤ j ≤ s）使 αj 可由前 j-1 个向量线性表示。再说明「同一个 η 的表示唯一」与「表示它的向量组线性无关」为什么等价。
  8. 设 η 是 n 维非零列向量，A 是 n 阶方阵，且 A^(m-1)η ≠ 0（m>2），A^mη = 0。证明 η, Aη, A²η, …, A^(m-1)η 线性无关，并写出两种不同的证法。
  9. 设 α1=(2,5,6)^T，α2=(0,a,0)^T，α3=(b,0,1)^T。求 a、b 满足什么条件时这组向量线性无关，什么条件下线性相关；必须写出行列式与低阶子式的依据。
  10. 设 α1,α2,α3 线性无关，β1=aα1+bα2，β2=aα2+bα3，β3=aα3+bα1。写出系数矩阵 C，计算 |C|，并由此判断 β 组在什么条件下线性无关；再说明当 b=-a 且 a≠0 时 β 组的秩是多少。
  11. 设 α1,α2,α3,α4 是任意四个同维向量，β1=α1+α2，β2=α2+α3，β3=α3+α4，β4=α4+α1。证明无论 α1..α4 取什么，β1..β4 都线性相关，并指出证明中哪一步只用到秩的不等式、哪一步用到了 |C| 的值。
  12. 把本章线索串起来：设 α1..αn 是 n 个 n 维列向量。证明「α1..αn 线性无关」等价于「任意 n 维列向量 η 都能由它们线性表示」，并说明这个等价关系分别用到了本章哪一条结论或定理（提示：两个方向各用一条）。
